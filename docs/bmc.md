# Business Model Canvas (draft — numbers are assumptions)

| Block | Draft |
|---|---|
| Customer segments | GAIAEZ / emirate Awqaf & IACAD facilities teams; ESCOs doing mosque retrofits; utilities running efficiency programmes |
| Value proposition | Know which mosques waste power and which AC units are failing — without a BMS, without cameras, for a few hundred dirhams per mosque |
| Channels | GAIAEZ facilities pilots; ESCO partnerships (bundled into their M&V); utility efficiency programmes |
| Customer relationships | Pilot → annual contract; monthly savings report; technician feedback loop |
| Revenue streams | Kit per mosque + monthly subscription per mosque, **or** shared savings with ESCOs (assumption — validate) |
| Key activities | Hardware assembly, installation coordination, model tuning, digest generation, support |
| Key resources | Sensor kit design, worship-calendar baseline, labelled fault data from pilots |
| Key partners | Licensed electrical contractors, ESCOs, GAIAEZ facilities, utilities |
| Cost structure | Hardware, installation labour, cloud/connectivity, support staff |
