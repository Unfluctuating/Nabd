# 90-day execution plan (draft)

| Weeks | Milestone | KPI |
|---|---|---|
| 1–2 | With GAIAEZ facilities, pick 3 small/old mosques outside existing programmes; licensed electrician installs kits; collect last 12 months of bills | 3 kits live, data flowing |
| 3–6 | Baseline period: no alerts yet; technicians log known events (repairs, Ramadan-style schedule changes) | ≥ 90% data uptime; every unit profiled |
| 7–10 | Alerts live in the daily digest; technicians Confirm / False-alarm each flag | % of flags confirmed; false-alarm rate per week |
| 11–13 | Report: kWh avoided, faults caught before failure, AED saved; go / no-go on 20-mosque rollout | Measured saving vs bill baseline |

Risks: data connectivity at old mosques (fallback: local logging + weekly upload); technician time to review flags (cap digest at 10 items/day).
